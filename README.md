# Horarium Classium

Այս repository-ն բաժանվել է երկու ինքնուրույն նախագծի։

- [Student](https://github.com/horarium-classium/student) — Windows, macOS և Linux desktop հավելված։
- [Scheduler](https://github.com/horarium-classium/scheduler) — դասացուցակի Teacher/Scheduler վեբ խմբագրիչ և Supabase backend։

Նոր մշակումները, issues-ը, CI-ն և release-ները կատարվում են համապատասխան նոր repository-ում։ Այս repository-ի նախորդ պատմությունը պահպանված է, սակայն դրա `master` branch-ն այլևս ակտիվ մշակման աղբյուր չէ։
